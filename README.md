# Оцифровка хакасско-русского словаря (под ред. О. В. Субраковой)

Проект по оцифровке, вычитке и коррекции электронного текстового варианта **«Хакасско-русского словаря»** (содержит около 22 000 слов, под общей редакцией доктора филологических наук О. В. Субраковой). 

Цель проекта — очистить текст от ошибок автоматического распознавания (OCR) и подготовить чистую электронную базу данных словаря.

## 🛠️ Встроенный инструмент редактора

Проект представляет собой один автономный `HTM`-файл. В него уже integrada удобная панель управления для быстрой ручной вычитки и правки текста прямо через браузер.

### Основные функции панели управления:
* **Мгновенный поиск:** поле поиска автоматически переносит экран к нужной словарной статье при вводе первых букв слова.
* **Быстрый ввод спецсимволов:** на панели выведены кнопки для хакасских букв (**Ғ**, **Ӱ**, **Ң**, **Ӌ**, **Ӧ**). Клик по ним дописывает букву в строку поиска в место курсора, не стирая уже введенный текст.
* **Правка «на лету»:** двойной клик по любой строке словаря превращает её в текстовое поле. Вы можете править текст и HTML-теги прямо на экране.
* **Горячие клавиши редактора:**
  * `Enter` (внутри текстового поля) — мгновенно сохраняет правоки в строке и закрывает её.
  * `Esc` — закрывает режим редактирования без сохранения изменений (отмена).
* **Синхронизация с диском:** кнопка `💾 Сохранить` перезаписывает изменения напрямую в ваш файл на компьютере (используется File System Access API браузера).

## 📝 Специфика текущей вычитки
Из-за особенностей автоматического сканирования исходный хакасский текст содержит типовые опечатки и ошибки распознавания (OCR). 

На данном этапе основной приоритет отдается **верификации реестра заголовочных слов** (названий словарных статей). Главная задача — обеспечить стопроцентную точность написания самих хакасских слов для корректной работы поиска, в то время как глубокая правка их внутренних определений и переводов является вторичной целью.
